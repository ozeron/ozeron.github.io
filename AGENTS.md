# Project Learnings

## Overview
- **Type**: Static Site / Blog
- **Stack**: Astro 5, Svelte, TypeScript, MDX
- **Package Manager**: Bun

## Architecture
- **Content**: Managed via Astro Content Collections in `src/content`
- **Styling**: Global styles in `src/styles`, scoped styles in Svelte components
- **Routing**: File-based routing in `src/pages`

## Key Commands
- `bun run dev`: Start development server
- `bun run build`: Build for production
